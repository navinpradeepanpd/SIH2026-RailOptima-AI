# Simulated Railway Data

**IMPORTANT**: The data contained in this directory is entirely **Simulation Data**. 

This prototype is built to demonstrate the capabilities of the RailOptima AI system, such as Data Normalization, Conflict Detection, Maintenance Priority Scoring, and Automatic Block Optimization. 

We do not have access to live Indian Railways systems (TMS, SMMS, TDMS, COA), so we use simulated JSON and CSV files to test and showcase these functions.

No real-world, live train operations are connected to this environment.
